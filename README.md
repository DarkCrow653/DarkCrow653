Development Philosophy
<div align="center">
BUILD WITH PURPOSE.
</div>
I believe good software development is more than choosing
the right framework.
It's about understanding the problem first.
```text
Problem
   ↓
Research
   ↓
Architecture
   ↓
Development
   ↓
Testing
   ↓
Deployment
   ↓
Iteration
```
Clean code matters.
Good UX matters.
Performance matters.
But above all:
The product needs to solve the problem it was built for.
